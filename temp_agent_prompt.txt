สร้างไฟล์ Markdown ชื่อ BOT_OVERVIEW.md สำหรับใช้เป็นเอกสารแม่ (Master Context Document) ของระบบบอทเทรด

วัตถุประสงค์:
- ใช้เป็น Single Source of Truth ของโครงการ
- ให้ Developer คนใหม่เข้าใจระบบได้รวดเร็ว
- ให้ AI Agent ตัวอื่นสามารถอ่านและทำงานต่อได้ทันที
- ใช้ติดตามความคืบหน้าการพัฒนา
- ใช้บันทึกประวัติการเปลี่ยนแปลง
- ใช้เป็น Context หลักสำหรับการพัฒนาระยะยาว

ข้อกำหนด:
- เขียนเป็น Markdown มาตรฐาน
- เขียนภาษาไทย
- รายละเอียดต้องครบถ้วน
- ห้ามสรุปสั้น
- ค้นหาข้อมูลในโปรเจกต์มาเติมให้สมบูรณ์ที่สุด (เช่น ชื่อไฟล์, กลยุทธ์, อินดิเคเตอร์)
- ทุกหัวข้อที่ข้อมูลยังไม่ทราบให้ใส่ TODO
- แสดงตัวอย่าง ตาราง รายการ และโครงสร้างให้พร้อมใช้งาน
- เอกสารต้องสามารถเปิดอ่านโดย AI ตัวใหม่แล้วเข้าใจโครงการทันที
