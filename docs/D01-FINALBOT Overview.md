## BOT_FINALBOT
## โหมดการทำงานของ BOT_FINALBOT (Trading Bot Modes)
บอทเทรดหลักในระบบรองรับการทำงานทั้งหมด **5 โหมด** ซึ่งกำหนดค่าผ่านไฟล์ [settings.json](file:///c:/Users/Administrator/Documents/GitHub/BOT_FINALBOT/config/settings.json) ในโฟลเดอร์ `config` (ระบุภายใต้หัวข้อ `"account"` -> `"trading_mode"`):

| โหมดที่ระบุใน Config | โหมดภายใน (Internal Mode) | อธิบายการทำงานโดยละเอียด |
| :--- | :--- | :--- |
| **`Signal_BOT`** | `SIGNAL` | **โหมดส่งสัญญาณอย่างเดียว:** ทำการอ่านและวิเคราะห์ข้อมูลตลาดเพื่อผลิตสัญญาณ CALL/PUT พร้อมค่าความเชื่อมั่น (Confidence score) แต่**ไม่มีการส่งคำสั่งซื้อขายจริง** |
| **`Auto_BOT`** | `TRADE` | **โหมดบอทเทรดอัตโนมัติ:** วิเคราะห์ตลาดและ**ส่งคำสั่งเทรดจริงโดยอัตโนมัติ**ไปยัง IQ Option (รองรับทั้งบัญชี PRACTICE/REAL) พร้อมตรวจสอบขีดจำกัดความเสี่ยง |
| **`Ai_BOT`** | `AI` | **โหมดบันทึกข้อมูลส่งต่อ AI:** ผลิตสัญญาณพร้อมข้อมูลอินดิเคเตอร์เชิงลึก แล้วเขียนเก็บลงในไฟล์ JSON เช่น `logs/pending_signals.json` เพื่อให้ระบบ AI ภายนอกดึงข้อมูลไปวิเคราะห์ประมวลผลต่อ |
| **`Hybrid_AiBOT`** | `HYBRID` | **โหมดผสมผสาน (บอท + AI):** บอทจะพบสัญญาณและเขียนข้อมูลลงไฟล์ JSON พร้อมสถานะ `"PENDING"` จากนั้นจะรอสัญญาณการอนุมัติการเปิดออเดอร์กลับมาจาก AI ภายนอก |
| **`Backtest_BOT`** | `BACKTEST` | **โหมดทดสอบย้อนหลัง:** จำลองการเทรดด้วยข้อมูลประวัติแท่งเทียนในอดีต (ระบุเวลาได้ใน config) โดยใช้ระบบเวลาจำลอง (`simulated_time`) และคำนวณผลสรุปกำไร/ขาดทุนแบบออฟไลน์ |
