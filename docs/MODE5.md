# แผนผังการทำงานของ Mode 5 (Backtest_BOT) แบบละเอียด

## 📌 บทสรุปผู้บริหาร (Executive Summary)
Mode 5 หรือ **Backtest_BOT** ไม่ใช่แค่ฟังก์ชันรันทดสอบธรรมดา แต่มันคือ **"เครื่องจำลองสภาวะแวดล้อม (Simulator) ผสมระบบอุดช่องโหว่ข้อมูล (Self-Healing Data)"** โดยมีหน้าที่หลัก 2 อย่างคือ:
1. เตรียมข้อมูลให้สมบูรณ์ 100% ก่อนเริ่มงาน (ถ้าข้อมูลประวัติวันนั้นขาดหาย ต้องดึงมาเติมเฉพาะส่วนที่ขาด)
2. สวมรอยเป็นกราฟแบบ Real-time เพื่อให้โหมด 2 (AUTO), โหมด 3 (AI), และโหมด 4 (HIBRID) สามารถทดสอบระบบตัวเองได้ในสภาพแวดล้อมที่เหมือนตลาดจริงที่สุด (โดยไม่ต้องกดออเดอร์เงินจริง)

---

## ⚙️ ขั้นตอนการทำงาน (Step-by-Step Execution)

### Step 1: การเตรียมความพร้อมและเข้าสู่ระบบ (Initialization & Broker Login)
*   **1.1 อ่านค่าเป้าหมาย (Target Configuration):** ระบบจะอ่านการตั้งค่าจากผู้ใช้ (เช่น วันที่ทดสอบ `2026-05-08`, กรอบเวลา `M5`, คู่เงิน `EURUSD`) และอ่านว่าจะให้สวมรอยเป็นโหมดไหน (เช่น สวมรอยเป็น โหมด 4 HIBRID_BOT)
*   **1.2 ล็อกอินโบรกเกอร์ (Mandatory Login):** บอทจะทำการล็อกอินเข้าสู่ IQ Option (ด้วยบัญชีเดโม่) เพื่อยืนยันตัวตน และดึง Token สำหรับใช้งาน API ในการดึงข้อมูลกราฟในขั้นตอนถัดไป

### Step 2: การซ่อมแซมและอุดรอยรั่วของข้อมูล (Data Patching & Self-Healing)
*   **2.1 สแกนไฟล์ในคลัง (Scan Local Storage):** บอทเข้าไปเช็คโฟลเดอร์เก็บข้อมูล (เช่น `backtest/data test/`) ว่ามีไฟล์ของวันที่ต้องการหรือไม่
*   **2.2 นับแท่งเทียน (Candle Validation):** ถ้าเจอไฟล์ข้อมูล บอทจะนับจำนวนแท่งเทียนทั้งหมด ตัวอย่างเช่นใน Timeframe 5 นาที (M5) 1 วันเต็มจะต้องมีแท่งเทียนทั้งหมด **288 แท่ง**
*   **2.3 ตรวจหาช่องโหว่ (Gap Detection):** ถ้าระบบพบว่ามีแค่ 200 แท่ง (แหว่งหายไป 88 แท่ง) บอทจะทำการเช็ค Timestamp ว่า "เวลาไหนถึงเวลาไหน" ที่หายไป
*   **2.4 ดึงข้อมูลเฉพาะจุด (Targeted Fetching):** บอทจะใช้ IQ Option API ร้องขอข้อมูลกราฟย้อนหลัง **"เฉพาะส่วนที่แหว่งไปเท่านั้น"** (ไม่ดาวน์โหลดใหม่ตั้งแต่ต้นให้เสียเวลา)
*   **2.5 ผสมผสานและเซฟ (Merge & Save):** นำแท่งเทียนที่ดึงมาใหม่ ประกอบร่างเข้ากับไฟล์เก่า เรียงลำดับเวลาให้เป๊ะ แล้วเซฟทับเพื่อให้ได้ไฟล์ข้อมูล 1 วันที่สมบูรณ์ 100%

### Step 3: การสร้างโลกจำลอง (Environment Mocking ด้วยข้อมูลจริง)
*   **3.1 สับสวิตช์กราฟ (Switch Data Feed):** บอทจะทำการ "ปิดตา" การดึงกราฟ Real-time ปัจจุบัน แล้วเสียบสายเชื่อมไปยังไฟล์ CSV ที่สมบูรณ์แล้วใน Step 2 แทน **(เน้นย้ำ: การจำลองในที่นี้คือการดึงราคา "จริง" ในอดีตจากไฟล์ .csv มาเล่นซ้ำเท่านั้น จะไม่มีการสุ่มหรือสร้างราคาปลอมขึ้นมาเด็ดขาด)**
*   **3.2 จำลองการเดินของเวลา (Time Travel Simulator):** บอทจะค่อยๆ ปล่อยข้อมูลแท่งเทียนออกมาทีละแท่ง เหมือนเวลากำลังเดินไปเรื่อยๆ ตามตลาดจริง
*   **3.3 บล็อกการกดออเดอร์ (Execution Override):** ถึงจะสวมรอยเป็น โหมด 2 หรือ 4 ที่มีการยิงออเดอร์ บอทจะต้อง **"บล็อกคำสั่ง Buy/Call/Put ที่ไปโบรกเกอร์จริง"** ทั้งหมด แล้วเปลี่ยนเป็นการ "บันทึกออเดอร์ลงสมุด (Paper Logging)" เพื่อคำนวณหา Win/Loss ในใจแทน

### Step 4: เริ่มการทำงานของโหมดที่เลือก (Execution Phase)
พอบอทจำลองโลกสำเร็จ มันจะปล่อยให้โหมดที่เลือกไว้ทำงานตามธรรมชาติ:
*   **รันผ่าน โหมด 2 (AUTO):** บอทวิเคราะห์ Indicator ตามปกติ -> ถึงจุดยิงสัญญาณ -> ยิงออเดอร์แบบจำลอง -> หักลบกำไรขาดทุน
*   **รันผ่าน โหมด 3 (AI):** บอทวิเคราะห์ -> ส่งข้อมูลผ่าน Prompt ตามอดีต -> AI (ฝั่งของจริง) ตัดสินใจ -> ส่งสัญญาณกลับมาพิมพ์โชว์
*   **รันผ่าน โหมด 4 (HIBRID):** บอทป้อนกราฟดิบในอดีต -> AI คิดแผนทั้งหมด -> AI สั่งยิงออเดอร์ -> บอทยิงออเดอร์จำลอง -> หักลบกำไรขาดทุน

### Step 5: สรุปและรายงานผล (Post-test Reporting)
*   เมื่อกราฟแท่งสุดท้ายของวันจบลง ระบบจำลองจะปิดตัว และคำนวณผลสรุปออกมา:
    *   จำนวนออเดอร์รวม (Total Trades)
    *   อัตราชนะ (Win Rate)
    *   กำไร/ขาดทุนสุทธิ (Net Profit)
    *   ความล่าช้า/ปัญหาการตอบสนองของ AI (ถ้ามีการรันโหมด AI/Hibrid)

## 💡 แนวทางการสั่งงาน DS ในอนาคต (Actionable Blueprint for DS)
เมื่อถึงเวลาให้ DS เขียนโค้ด เราจะต้องแบ่งคำสั่งให้ชัดเจนเพื่อไม่ให้บอทรวน:
1. **งานที่ 1: ระบบ Data Manager (Step 2)** สั่งให้ DS เขียนคลาสที่เก่งเรื่องการเช็ค Gap ข้อมูลไฟล์ CSV และเชื่อมต่อ API IQ Option เพื่อขอแท่งเทียนแบบเจาะจงเวลามาปะผุ
2. **งานที่ 2: ระบบ Simulator Switch (Step 3)** สั่งให้ DS สร้างอแดปเตอร์ใน `runner.py` ที่สามารถ Override ข้อมูลของ `get_candles` เป็นการอ่านจาก DataFrame แทนการเรียก API
3. **งานที่ 3: ระบบ Fake Executor** สร้างตัวจัดการออเดอร์ (Mock Trade Order) ที่ไม่ยิงเงินจริงแต่คำนวณ PnL จากราคา Close ของแท่งเทียนถัดไปแทน
