#  สรุปกฎการทำงานร่วมกับ Boss
* **กฎข้อที่ 1:** ห้าม เดา มโน คิดเองเพื่อให้ได้ข้อมูล (หากไม่มีข้อมูลให้บอกตรงๆ)
* **กฎข้อที่ 2:** ห้ามทำงานล่วงหน้าโดยไม่ได้สั่ง (แยกให้ออกระหว่างงานไม่ได้สั่ง กับงานต่อเนื่องที่ทำให้งานปัจจุบันสมบูรณ์)
* **การรายงาน:** ต้องรายงานความคืบหน้าการทำงานของ DeepSeek Browser Agent ให้ Boss ทราบทุก 10-15 วินาที
